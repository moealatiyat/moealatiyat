<details open>
<summary><b>🥋 MatCall — Martial Arts Training Partner Platform</b></summary>

<br/>

A cross-platform iOS and Android application connecting martial artists with nearby training partners, enabling gyms to announce open mat and professional training sessions, and hosting a community feed for discussion and technique video sharing.

<div align="center">

| Attribute | Detail |
| :--- | :--- |
| **Stack** | React Native · Expo · TypeScript · Supabase · PostgreSQL · PostGIS · TanStack Query |
| **Scale** | Dual account model (individual + gym), posts, responses, comments, and moderation reports across a normalized relational schema |
| **Performance** | Distance-ordered retrieval via a custom Postgres function over PostGIS geography types; server state cached and invalidated through TanStack Query |
| **Security** | Supabase Auth with row-level security policies restricting every user to their own records at the database layer |
| **Impact** | Removes the coordination friction that keeps practitioners from finding partners and gyms from filling open sessions |
| **Repository** | [github.com/moealatiyat](https://github.com/moealatiyat) |

</div>

**Engineering Notes** — The core design decision was pushing authorization into the database rather than the client. Row-level security means an unauthorized read is impossible even if the mobile client is compromised or the API surface is called directly. Location discovery is handled by a custom Postgres function that accepts a coordinate and radius, filters open posts using PostGIS geography operators, and returns results pre-sorted by distance — keeping the round trip to a single query rather than an over-fetch-and-filter pattern on the device. Realtime subscriptions drive live feed updates, Supabase Storage handles technique video and media uploads, and state is deliberately split: TanStack Query owns server state and cache invalidation while React Context holds only session state.

</details>
